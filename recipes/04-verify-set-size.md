# 🔍 Recipe 04 — Verify a set size (MUST)

`city_info` returns **at most 5 cities**. Argentina showed 5 and is 11.

- Listing shows **< 5** → size proven (Mexico 3, Canada 3, Japan 3, Uruguay 3, Bolivia 4).
- Listing shows **exactly 5** → **unknown**. Do not commit slots. Proven only by the `x/N` on a first buy.
- Buying one city to learn N costs a flight and possibly a stranded slot. Prefer countries already proven small, one cab hop from the cluster.
- Also check every listed city is **for sale** — one rival-held city blocks the set (Netherlands: Rotterdam).
