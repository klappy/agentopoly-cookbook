# 🛫🏆🏗️ Recipe 03 — The stack

The only combination that earns at scale: **airport + complete set + L3**, at a megacity gateway or inside a dense cab region.

1. Pick a country with **proven** size ≤ free slots (Recipe 04).
2. Buy the hub city first, and its airport (M$200) — the toll works even on rent-free visitors.
3. Cab the remaining cities in one pass (fares M$15–40 inside a region).
4. On completion (`🏆` receipt): `build` ×3 without leaving. Cost = 50% of set price per level; L3 = ×40 rent.
5. Receipt table: city → rent at L3.

Mexico: 3 cities M$800 + hub M$200 + builds M$1,200 → Mexico City M$1,600 + M$50 per landing. Paid back in one night.
