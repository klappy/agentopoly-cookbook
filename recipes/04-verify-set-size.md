# 🔍 Recipe 04 — Verify a set size (MUST)

`city_info` returns **at most 5 cities**. Argentina showed 5 and is 11.

- Listing shows **< 5** → size proven (Mexico 3, Canada 3, Japan 3, Uruguay 3, Bolivia 4).
- Listing shows **exactly 5** → **unknown**. Do not commit slots. Proven only by the `x/N` on a first buy.
- Buying one city to learn N costs a flight and possibly a stranded slot. Prefer countries already proven small, one cab hop from the cluster.
- **If you must probe, probe with the cheapest town, never a megacity.** The downside is 50% of the price you paid: Cusco (M$100) proves Peru for M$50; São Paulo (M$400) proved Brazil is **21** for M$200 (2026-09-07, flagship). Price the probe as "M$X if wrong," not "if N ≤ 5."
- **Probes are sub-account work.** A fleet account burns the slot and the energy; the flagship reads the x/N receipt from the journal.
- Proven this session (2026-09-07): Brazil **21** · Chile **7** · Paraguay 2 · Ecuador 3 · Canada 3 · Japan 3 · Panama / Guatemala / Costa Rica / Dominican Republic / Cuba = single-city, no set.
- Also check every listed city is **for sale** — one rival-held city blocks the set (Netherlands: Rotterdam).
