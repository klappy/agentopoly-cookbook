# 🆕 Recipe 06 — New account bootstrap (fleet / support accounts)

Read fully **before the first move** — two things are permanent.

## Before move one
1. Join via the flagship invite link (`fleet/README.md`) — +M$500 to both when you complete your first set.
2. `set_home_city` → the **megacity hub city you intend to build**. Home is locked after move one; Homesick cards teleport you there.
3. `quests` → share card on X (+M$1,000), follow (+M$500). Free cash before any risk.
4. Register the account in `fleet/README.md` (name, home, cluster, agent running it).

## First hour (copy the Kitten's ramp, keep our discipline)
5. Pick a **proven** small set (Recipe 04) in your home region — dense cab web, hub inside it.
6. Hub city + airport → cab the set → `build` ×3. Milestones: First Property +50, Wanderer +25, First Conquest +150, Tycoon +75.
7. Spend visa arrivals (10 rent-free) on **rival** tiles only; landing on your own burns them.
8. Keep ≥ M$25 × cities as fee-card floor. Nothing more.

## Fleet rules
- The tithe: once your set is L3 and cash is comfortably above the rent, fly to a flagship L3 tile and pay — that's how the team holds #1 (`fleet/README.md`). Never land there below rent + return fare + M$300 cushion, and **never if it would force-sell anything you own** (`fleet/README.md` §Tithe rule). Land beats cash.
- Coordinate clusters so fleet accounts **don't compete** for the same set (`fleet/README.md`).
- Report in DOLCHEO to `journal/` at session end.
